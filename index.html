How to use

Game view scrolls colour-coded notes toward the hit line (like the drum tutor). Fingering view shows the staff on top and one lane per key below — blocks arrive at circles that light up when that key should be down. Notation view shows the staff; tap a bar to set the loop start, tap another to set the end.

Playing: connect your Aerophone with Connect MIDI (Chrome/Edge on desktop or Android), or use Mic with a real sax (headphones recommended). First time with MIDI, press Calibrate MIDI and play the first note — that fixes any octave/transposition difference.

Practice tools: slow it down, loop a few bars, Wait for me, swing, and Practice all keys to run a lick around the circle of 4ths.

Import: MIDI or MusicXML transcriptions, or type a lick. Pick whether the file's pitches are concert or written for your horn. Chord symbols in a MusicXML file become the chord chart automatically.

Fixing an import: press ✎ Edit notes in the notation view, tap a note, and change its pitch, length or position, add a note after it, or delete it. Undo steps back. Built-in licks are copied first, so the original stays as it was.

Backing track: chords show above the notes (transposed for your horn). The app can play a generated bass, piano and drums from the chords (Swing, Ballad or Bossa). For an imported MIDI file with other tracks, it can play the original band instead. Use ✏ Chords… to type or edit the chart.

Step through: use Prev/Next note (or ← →) to move one note at a time and see the fingering. Tick Advance when I play it to move on whenever you play the shown note.

Shortcuts: Space start/pause · Esc stop · V switch view. Fingerings are standard (written B♭3–F♯6, including palm keys); altissimo above that isn’t charted.
